## 📌 概要 (Overview)

### 開発の背景と目的
ビジネスの現場において、「言いたいことが相手に伝わらない」「資料に文字を詰め込みすぎて要点がぼやける」「合意形成に時間がかかりタスクが進まない」という課題は後を絶ちません。その根本的な原因は、自己中心的な「伝えたつもり」に陥り、情報が構造化されていない点にあります。

**`basic-communication-tools`（BCT）** は、**「主格を相手（聴き手）に置く」** 思考様式を基盤とし、情報を論理的・構造的に整理・視覚化して、相手の確実な理解と迅速な意思決定を引き出すための実践的フレームワーク集です。

### 思考と伝達を支える2大体系
単なるスライド作図のテクニックではなく、**「思考の整理」から「実務の実行」までを直結させるメソッド**として体系化されています。

1. **ツリー構造系（論理3構図） — タスク活動起動メソッド**  
   業務やプロジェクトを立ち上げる際の一連の実行サイクル：  
   `【Step 1: 課題抽出】ブレイクスルー構図` ➔ `【Step 2: アクション化】3点並列構図` ➔ `【Step 3: スケジュール化】時系列構図`
2. **マトリックス構造系（分析2構図） — 意思決定・状況把握メソッド**  
   二次元の視座で客観的な事実や位置づけを可視化する体系：  
   `【分析構図 1】対比構図（優位性の立証）` ＆ `【分析構図 2】座標軸構図（ポジショニングと全体像）`

### 想定される活用シーン
- **新規企画・改善提案**: 現状の課題と目指すべき理想のギャップを明快に示し、提案を通す
- **進捗報告・タスク管理**: 業務アクションの切り口を揃え、時系列で遅延や因果関係を共有する
- **複数案の比較検討**: 評価軸を統一したマトリックスにより、客観的な優位性を立証する
- **組織内ファシリテーション**: 議論の空中戦を防ぎ、チームの共通言語として合意形成を迅速化する

本リポジトリでは、ブラウザで即座に上映できる **インタラクティブHTMLスライド（全34枚）** と、そのまま印刷・配布できる **ベクター品質PDF（全34ページ）** を提供しています。

## 🚀 特徴 (Key Features)

- **プロフェッショナル・ダークテーマ（高コントラスト設計）**  
  GitHub/モダンテック風の高コントラスト・ダークデザインシステム（`#0d1117` / `#161b22`）を採用。明快なカラーコーディング（グリーン、シアン、ブルー、オレンジ、パープル）により、直感的な視線誘導と高い視認性を実現。
- **「図解（構図モデル）」と「実践解説」の完全セパレート構成**  
  窮屈な詰め込みを排除し、各重要テーマを「横幅いっぱいに拡大した視覚図解スライド」と「構造化された要点・実践解説スライド」の2ページ構成に分離。プレゼン時の視認性と研修テキストとしての理解度を両立。
- **原典（BCTハンドブック＆研修テキスト）の完全再現**  
  「3点設定の4ルール（自立性・等量性・等形性・等階層性）」「訴求（キャッチ）ポイントの設定」「時系列の切り口統一」「ブレイクスルーの4要素（問題点・原因・対応・理想）」など、原典の論理と具体的事例を忠実に網羅。
- **直感的なプレゼンテーションUI**  
  矢印キー（`←` / `→`）やスペースキー、画面下部のプログレスバーによる軽快なスライド操作に対応。
- **全スライド一覧（モーダル俯瞰）**  
  `O` キーまたは一覧ボタンで、全34スライドのサムネイルをグリッド俯瞰可能。アジェンダ確認や質問対応時のクイックジャンプに最適です。
- **高品質PDF出力同梱**  
  16:9比率に完全最適化した `Basic_Communication_Tools_Slides.pdf`（全34ページ）をリポジトリ直下に同梱。

## 🖥️ 閲覧・利用方法 (Usage)

### 1. Webブラウザで閲覧（ローカル）
リポジトリをクローンまたはダウンロード後、ブラウザで直接開くだけでプレゼンテーションが開始できます。

```bash
git clone https://github.com/<ユーザー名>/basic-communication-tools.git
cd basic-communication-tools
```

ファイル一覧から `index.html` または `slide.html` をダブルクリックして開いてください。

#### 操作キー一覧
| 操作 | キー / アクション |
| :--- | :--- |
| 次のスライドへ | `→` / `Space` / `PageDown` / 右下 `▶` ボタン |
| 前のスライドへ | `←` / `PageUp` / 右下 `◀` ボタン |
| 全スライド一覧切替 | `O` キー / 右下 `☷` ボタン |
| 一覧モーダルを閉じる | `Esc` キー / 背景クリック |
