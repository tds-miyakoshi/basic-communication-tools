問題解決をスタートさせる起点

プロジェクトやタスクの第一歩は、「何が問題で、どこを目指すのか」を明確に定義することです。

ブレイクスルー構図の特徴

  • ギャップの可視化：「現状（問題点）」と「理想（目標）」の高低差を明確にする
  • 真因へのフォーカス：表面的な現象ではなく、根本的な原因を徹底追求する
  • 1対1の対応策：洗い出した原因を確実に潰す改善策を立案する

Step 1 Technique // 原因追求と対応策立案

ブレイクスルー構図の完成順序と実践ポイント

SECTION 2-3

完成させる4つのステップ

  1. 第1次階層の選出：「問題点」「理想」「原因」「対応」の4大要素を設定
  2. 現状とゴールの確定：問題点と理想の状態を具体化・言語化する
  3. 原因の徹底追求（最重要）：問題を生み出した真の要因を残らず洗い出す
  4. 対応の立脚：洗い出した原因を一つずつ丁寧に潰す具体策を導く

実務における最重要ポイント

⚠️ 原因追求が甘いと再発する：
対症療法（表面的な対応）に走ると、根本的な問題は放置されたままになります。
  • 「なぜ？」を掘り下げ、構造的な原因に到達するまで追求する。
  • 対応策は抽象論で終わらせず、次ステップ（3点並列構図）でアクションに落とし込める粒度にする。

Cognitive Logic // なぜ「3点」なのか？

第一次階層を3点に絞る2大根拠

SECTION 2-1
根拠 ①

「聴き手の記憶に残る」

人間のワーキングメモリの許容量は3点程度です。

4点以上になると情報過多で記憶から脱落し始めます。

「2点」では不足する理由：
2点では単なる「二者択一」や「対立」に見え、物事を立体的に捉えられず不安感が残ります。3点あって初めて安定した立体像が脳内に完成します。

根拠 ②

「聴き手を説得できる」

「3」は古今東西、心理学・修辞学的に人を最も納得させる黄金数です。

歴史的・文化的な安定の証：
・三顧の礼
・心・技・体
・衣・食・住
・三位一体

冒頭に「ポイントは3点です」と宣言することで、相手の脳内に3つのフォルダが準備され、説得の受容態勢が整います。

聴き手は2点目を聞いた段階で3点目を予測します。3点全てがこのベクトル上にあることで完全な納得が生まれます。

Step 3 Technique // 報告・計画の精度向上

時系列構図の技術：「切り口の統一」

SECTION 2-2

時間軸のノード（第一次階層）を並べる際、最も重要なのは「切り口の次元を揃える」ことです。

✕ 悪い例（混在）
「1週間前、企画作成時、プレゼン時」

時間（1週間前）と業務アクション（作成時・プレゼン時）が混在し、聴き手の頭にノイズが生じます。

◯ 良い例（基準統一）
「企画依頼時、企画作成時、プレゼン時」

業務アクションの切り口で一貫しているため、プロセスの因果関係が明快に伝わります。

◎ 最高に良い例（併記）
「依頼時（1週間前）、作成時（〜昨日）、プレゼン時（本日）」

業務アクションを主格にしつつ、具体的な時間情報をカッコで補足する理想的な記述です。

Presentation Mindset // 役割分担

スライド・語り・資料の「3階層分担」

HANDBOOK GUIDE

主役は誰か？

よくある大失敗：
スライドに細かい長文を詰め込み、プレゼンターが棒読みする。
→ 聴き手は読むことに疲れ、話を聞かなくなります。
主役は説明する「プレゼンター」！

スライドはあくまで道しるべ（第一次階層）。プレゼンターの言葉・熱量（第二次階層）が加わって初めて説得が成立します。

PPTスライド ＝ 第一次階層 骨子・道しるべ

論点タイトル、キーワード、直感的な図解のみを投影。長文は徹底排除する。

プレゼンター ＝ 第二次階層 主役

スライドの論点を自分の言葉で肉付けし、背景・理由・具体策を熱意を込めて語る。

配布資料 ＝ 第三次階層 証拠データ

詳細データ、計算根拠、仕様書など、後から手元で検証するためのエビデンス。

Delivery Techniques // デリバリー技法

非言語コミュニケーションの極意

HANDBOOK GUIDE

声の調子：4Pの法則

声の抑揚とコントロールで聴き手を惹きつけます。

  • Pitch（高低）：音の高低差で感情と重要度を伝える
  • Pace（速度）：重要な結論はあえてゆっくり語る
  • Power（音量）：会場の最後列に届く十分な声量
  • Pause（間）：沈黙を使い、次の言葉への注目を集める

ジェスチャー：5つの禁じ手

無意識の仕草が説得力を削ぎ落とします。

  • ① 手を前に組まない（防御姿勢に見える）
  • ② 手を後ろに組まない（偉そう・隠し事の印象）
  • ③ 手をポケットに入れない（不誠実に見える）
  • ④ 腕組みをしない（拒絶・威圧感を与える）
  • ⑤ 手を神経質に動かさない（ペン回し、服いじり等）

Delivery Techniques // 視線・傾聴・準備

相手を惹きつける視線と傾聴の技術

HANDBOOK GUIDE

アイコンタクト：「Zの法則」

視線を会場の左上 ➔ 右上 ➔ 左下 ➔ 右下と「Z字」に動かして全体を包み込みます。

キーマン注視：
全体を見渡しつつ、意思決定権を持つキーマンに視線をしっかり合わせて反応を確かめます。

外見とスマイル：TPOに合わせた清潔感と、要所での自然な笑顔が警戒心を解きます。

アクティブ・リスニング（質疑応答）

質疑応答では「聞く力」がプレゼンターの信頼を決定づけます。

  • うなずき・相槌：相手の話を真摯に受け止める
  • 復唱・要約（サマライズ）：「〜というご質問ですね」と整理してから回答する
リハーサルの極意：
原稿を丸暗記せず、「構図のキーワード」を頼りに何度も声出し練習を行います。
